工具

需要下载以下工具，我使用的是命令行操作： win + r → cmd

  1. Python –version
  2. node -version
  3. npm –version
  4. opencode –version

以上工具如何安装，询问 ChatGPT 即可。

基础配置

  1. 直接在命令行中输入 opencode 即可打开 opencode 界面。

  2. 在对话框中输入 /connect 配置模型，有无数个模型，我因为有 ChatGPT Plus 订阅，所以配置了 OpenAI。（这里有一点非常坑，需要梯子开虚拟网卡模式，我用的是 Clash verge，系统代理完全不能用）

  3. 配置完成后，在对话框中输入 /models 即可选用模型。

  4. 常用命令为 /new 和 /sessions 这两个，一个是新建对话，一个是查看过往所有对话。

  5. 另外一点有个坑，就是 opencode 回复时，经常会用英文。可以在全局配置中设置一下：C/用户/用户名/.config/opencode/ 这个文件夹下，创建一个 AGENTS.md 文件，写上：

    验证一下，开一个对话框，问：who are you？如果回复是中文，就完成了。

skills

同样也是放到上面那个文件夹中，这里是全局配置，也可以放在你要工作的文件夹中。

然后每个 skills 都是一个单独的文件夹，里面会有各种各样的文件，最重要的就是 SKILL.md。

安装之后，可以打开对话框问一下，我都有哪些 skills。
